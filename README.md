# LivioNet

**LivioNet** is a video-based deep learning model designed for automated analysis of liver ultrasound. Unlike traditional approaches that rely on static images, LivioNet captures spatiotemporal features from ultrasound videos, enabling more accurate detection of liver fibrosis and steatosis in patients with chronic liver disease.

## Highlights

- Focuses on **dynamic ultrasound signals**, overcoming the limitations of static-image methods.
- Incorporates an attention mechanism to emphasize diagnostically relevant temporal segments.

This repository contains the core model architecture and experimental pipeline used in our research.

*This project is under active development. Full documentation and code release are planned.*
